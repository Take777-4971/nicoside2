# NicoSide

YouTube / ニコニコ動画を検索・再生できる、デスクトップの端に常駐させて
使う「サイドバー型ガジェット」デスクトップアプリです。

技術的な開発経緯・実装上の工夫・実機で見つかった不具合の調査ログは
[DEVELOPMENT.md](./DEVELOPMENT.md) にまとめてあります。このファイルは
アプリの概要・使い方・セットアップ方法をまとめたものです。

## 主な機能

- **検索**: YouTube / ニコニコ動画をキーワードで検索。並び替え（再生数順・
  投稿日時順など）にも対応
- **再生リスト / マイリスト**
  - YouTube: ログイン中アカウント自身の再生リストを表示・選択
  - ニコニコ動画: 公開マイリストのURL/ID手動登録、またはログインして
    自分の非公開マイリストも含めて自動表示
- **動画再生**: アプリ内に埋め込んで再生（ニコニコ動画はコメント表示にも
  対応、プレーヤー標準機能で切り替え可能）
- **リピート再生**: 1曲リピート / リストリピート（**YouTubeのみ対応**。
  ニコニコ動画は技術的な制約により非対応、詳細は下記「既知の制限」参照）
- **ウィンドウ管理**
  - サイズ切り替え（x1 / x2 / x3）
  - ドラッグでの画面端スナップ（タスクバーを避けて配置）
  - 「自動的に隠す」モード（画面端に畳まれ、マウスを近づけると展開）
  - 常に最前面表示
  - 前回終了時の位置・サイズを記憶し、次回起動時に復元
  - タイトルバー無し。上部の帯部分・区切り線をドラッグして移動

## ファイル構成

```
nicoside_pyweb/
├── main.py               # ウィンドウ起動処理
├── api.py                # JS(UI) <-> Python ブリッジ（js_api）。検索・
│                          # ページング・ウィンドウ操作を担当
├── auth.py                # YouTube OAuth 2.0（InstalledAppFlow）
├── nico_auth.py            # ニコニコ動画の非公式ログイン（メモリ上のみ保持）
├── config.py                # ウィンドウ位置・サイズ等の設定の保存/読込
├── paths.py                   # exe化時/開発時のファイルパス解決
├── providers/
│   ├── base.py                 # プロバイダ共通インターフェース
│   ├── niconico.py              # ニコニコ動画（検索・マイリスト・埋め込みURL）
│   └── youtube.py                # YouTube Data API v3
├── ui/
│   ├── index.html
│   ├── style.css
│   └── app.js
├── requirements.txt
├── main.spec              # PyInstaller用ビルド設定
├── README.md              # このファイル
├── DEVELOPMENT.md         # 開発ログ・技術的な経緯（詳細版）
└── HANDOFF_SUMMARY.md     # 別チャットへの引き継ぎ用サマリー
```

実行時にexeと同じフォルダ（開発時はプロジェクトフォルダ直下）に、
以下のファイルが作成・使用されます。

| ファイル | 内容 |
|---|---|
| `client_secret.json` | YouTube機能を使う場合に必要（後述、開発者が用意） |
| `token.json` | YouTube OAuthログイン後のトークン（自動生成） |
| `config.json` | ウィンドウ位置・サイズ等の設定（自動生成） |
| `nico_mylists.json` | 登録した公開マイリストの一覧（自動生成） |
| `.webview_data/` | WebView2のCookie・キャッシュ等（自動生成） |
| `nico_session_dev.json` | 開発用フラグ有効時のみ生成（後述） |

## セットアップ

### 必要環境

- Windows 10/11（Edge WebView2 Runtimeが必要。通常は標準搭載済み）
- Python 3.10以上

### インストール

```
pip install -r requirements.txt
```

Windowsで実行する場合は、以下も追加でインストールしてください。

```
pip install pythonnet pywin32 comtypes
```

### YouTube機能を使う場合

YouTubeの検索・再生リスト機能を使うには、`client_secret.json`が
プロジェクトフォルダ（exe化した場合はexeと同じフォルダ）に必要です。
Google Cloud ConsoleでOAuthクライアント（種類: デスクトップアプリ）を
作成し、ダウンロードしたJSONファイルをこの名前で配置してください。
ニコニコ動画の検索・再生・マイリストのみを使う場合は不要です。

### 起動（開発時）

```
python main.py
```

### exe化

```
pyinstaller main.spec
```

生成される`dist/main.exe`は単独で動作しますが、YouTube機能を使う場合は
`client_secret.json`を同じフォルダに配置してから起動してください。

## 使い方

1. 検索キーワードを入力して🔍で検索、またはEnterキー
2. 「ソース」でYouTube / ニコニコ動画を切り替え
3. 「並び替え」で検索結果の並び順を変更（ソースによって選べる項目が
   異なります）
4. 検索結果の動画をクリックすると、アプリ内で再生されます
5. 「再生リスト」/「マイリスト」のドロップダウンから選ぶと、その中身が
   一覧表示されます
   - YouTube: 👤ボタンからログインすると、自分の再生リストが選べます
   - ニコニコ動画: ＋ボタンで公開マイリストをURL/IDで登録できます。
     🪪ボタンからログインすると、非公開のものも含めて自分のマイリストが
     自動的に一覧に表示されます
6. 🔁ボタンでリピート再生の設定（YouTubeのみ有効）
7. 📌ボタンで「常に最前面」「自動的に隠す」「OFF」を切り替え
8. ⛶ボタンでウィンドウサイズ（x1/x2/x3）を切り替え
9. ウィンドウ上部の帯（タイトルバー相当）をドラッグすると移動できます。
   画面端に近づけると吸着します
10. ウィンドウを閉じると、位置・サイズが記憶され、次回起動時に復元されます

## ニコニコ動画ログインについて（重要）

ニコニコ動画には、YouTubeのOAuthに相当する公式なログイン手段が
提供されていないため、非公式な方式（別ウィンドウで通常のログイン画面を
開き、ログイン完了後にそのセッションを取得する）を採用しています。

ログイン情報は**アプリ終了と同時にメモリ上から失われ、通常はディスクに
一切保存されません**。次回起動時は必ず再ログインが必要です。これは
セキュリティ上の意図的な設計です。

開発中の動作確認を目的として、`nico_auth.py`内の
`PERSIST_SESSION_FOR_DEV`という変数を`True`にすると、ログイン情報を
ディスクに保存し、次回起動時も自動的に使えるようになります。
**この設定は開発時専用です。一般公開する場合は必ず`False`に戻して
ください。**

## 既知の制限

- ニコニコ動画のマイリスト機能・ログイン機能は、いずれも非公式・
  未文書化のAPIを使用しています。ニコニコ側の仕様変更で、予告なく
  動かなくなる可能性があります
- ニコニコ動画の埋め込み再生も、非公式に特定したURLパラメータの組み合わせに
  依存しているため、同様のリスクがあります
- リピート再生（1曲リピート・リストリピート）はYouTubeのみ対応です。
  ニコニコ動画は、埋め込みプレーヤー側に外部から動画終了を検知・制御する
  手段が無く、技術的に実現できないと判断しています（詳細な調査経緯は
  DEVELOPMENT.mdを参照）
- リストリピートは、現在表示中のページ（最大20件程度）が対象です。
  検索結果全体（最大100件）や複数ページをまたいだ連続再生には対応して
  いません
- ウィンドウのリサイズ時に、再生中の動画の解像度がリアルタイムで
  追随するかは未検証です

## ライセンス・利用上の注意

- YouTube Data API・ニコニコ動画スナップショット検索APIは、いずれも
  各サービスの利用規約に従って利用してください
- ニコニコ動画のスナップショット検索APIは、営利目的での利用が禁止
  されています
- 一般公開・配布する際は、プライバシーポリシーの用意など、YouTube API
  利用規約が定める要件への対応が必要です
